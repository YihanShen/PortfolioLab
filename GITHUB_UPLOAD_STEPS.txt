PortfolioLab GitHub Upload Steps
================================

This project is already a git folder, but most project files are currently
untracked. The steps below prepare a clean first upload to GitHub.


1. Check The Project Folder
---------------------------

Open a terminal and go to the project folder:

cd /Users/harrysyh/Desktop/Projects/PortfolioLab

Check what git sees:

git status --short --ignored

You should expect source files such as README.md, pyproject.toml, src/,
strategies/, notebooks/, and tests/ to be untracked before the first commit.

The following should stay ignored:

- portfoliolab_venv/
- data/yahoo_prices.csv
- data/catalogs/yahoo_us_catalog.json
- __pycache__/
- .pytest_cache/

Those are local environment/cache files and should usually not be uploaded.


2. Run Tests Before Uploading
-----------------------------

Use the local environment:

source portfoliolab_venv/bin/activate
PYTHONPATH=src python3 -m pytest -q

Optional:

PYTHONPATH=src python3 -m unittest discover -s tests

Only continue if the tests pass.


3. Create A GitHub Repository
-----------------------------

On GitHub:

1. Click New repository.
2. Name it something like PortfolioLab.
3. Choose Public or Private.
4. Do not initialize it with a README, .gitignore, or license if you want to
   push this local folder as-is.
5. Copy the repository URL, for example:

https://github.com/YOUR_USERNAME/PortfolioLab.git


4. Stage The Project Files
--------------------------

From the project folder:

git add .gitignore README.md pyproject.toml src strategies tests notebooks data/.gitkeep GITHUB_UPLOAD_STEPS.txt

Check the staged files:

git status --short

Make sure ignored local data/venv/cache files are not staged.


5. Make The First Commit
------------------------

git commit -m "Initial PortfolioLab research console"


6. Connect To GitHub
--------------------

If the repo has no remote yet:

git remote add origin https://github.com/YOUR_USERNAME/PortfolioLab.git

If a remote already exists and you need to update it:

git remote set-url origin https://github.com/YOUR_USERNAME/PortfolioLab.git

Check it:

git remote -v


7. Push To GitHub
-----------------

Check your current branch:

git branch --show-current

If the branch is main:

git push -u origin main

If the branch is master:

git push -u origin master

If you want to rename master to main first:

git branch -M main
git push -u origin main


8. After Uploading
------------------

Open the GitHub repo page and check that these are visible:

- README.md
- pyproject.toml
- src/portfoliolab/
- notebooks/
- strategies/
- tests/
- data/.gitkeep

Also check that these are not visible:

- portfoliolab_venv/
- data/yahoo_prices.csv
- data/catalogs/yahoo_us_catalog.json
- __pycache__/
- .pytest_cache/


9. Future Updates
-----------------

After making changes:

git status --short
git add FILES_YOU_CHANGED
git commit -m "Describe the update"
git push

For example:

git add README.md src tests strategies notebooks
git commit -m "Improve strategy and neutralization editors"
git push


10. Optional: Keep A Local Data Snapshot Separately
--------------------------------------------------

The downloaded market data cache is ignored because it can grow large and can
be refreshed from yfinance. If you ever want to share a reproducible small
sample, create a separate small sample file with a clear name, such as:

data/sample_prices.csv

Then update .gitignore carefully so only that sample file is included.
